# 🌤️ Weather UI

A simple and responsive Weather Application built using React.js and Vite.  
It uses the OpenWeather API to fetch and display real-time weather information for different cities.

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Displays current temperature
- 💧 Shows humidity
- 🌤️ Shows weather condition
- 🌡️ Displays minimum and maximum temperature
- 🤗 Shows "feels like" temperature
- 📱 Responsive user interface
- ⚡ Fast development with Vite

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- HTML
- CSS
- Material UI
- OpenWeather API
